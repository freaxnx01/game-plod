# i18n: DE/EN Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add DE/EN i18n to `index.html` (default EN, auto-detected from
`navigator.language`, manually overridable via a HUD toggle, persisted in
`localStorage`), covering every player-facing string in the game.

**Architecture:** A `STRINGS = { en, de }` dictionary and a `t(lang, key, vars)`
lookup helper added near the top of the embedded script. JS-built strings
call `t()` directly; template-bound strings (rendered via `{{ }}`) get a
thin getter wrapping `t()`, since the template engine only resolves
property paths, not call expressions.

**Tech Stack:** Vanilla JS, single self-contained `index.html`, no build
step, no test framework.

## Global Constraints

- `index.html` is normally a generated dc-tool bundle; no source file exists
  in this repo for game-plod (same situation as issue #5 — confirmed
  previously, hand-editing `index.html` directly is the approved approach).
- The plodder/UI logic lives inside a `data-dc-script=""` HTML attribute
  whose value is a JSON-escaped string: literal newlines are the two-byte
  sequence `\n` (backslash+n) and double quotes are `\"` (backslash+quote).
  Every code snippet touching that region in this plan uses those literal
  escaped sequences exactly as shown — copy them verbatim.
- Special characters already present in that region (`·` U+00B7, `×`
  U+00D7, `–` U+2013, `←` U+2190, the curly apostrophe `’` U+2019) appear
  as real, literal UTF-8 characters, **not** `\uXXXX` escapes — new German
  text (ü, ä, ö, ß) follows the same convention: write the real UTF-8
  character, do not `\u`-escape it.
- Forward slashes inside that region are written as `\u002F` (e.g. closing
  tags are `<\u002Fdiv>`). To avoid needing forward slashes at all in the
  new `t()` helper, its token-replace uses `new RegExp("\\{(\\w+)\\}", "g")`
  instead of a `/…/g` regex literal.
- **Scope correction from investigation:** the spec's `navRestart` key does
  not correspond to a real separate string — the only "Restart" text is
  the paused-screen button, already covered by the `restart` key. Do not
  add a `navRestart` key. The bundler-injected footer hub-nav (the
  "Game navigation" bar with More Games/Source/Feedback/Star links, added
  near the very end of the file, **outside** the `data-dc-script` blob) is
  shared boilerplate across every `game-*` repo in this hub and is **out of
  scope** — do not translate it.
- The in-game "← identity board" back-link (inside the blob) **is** in
  scope, covered by the `identityLink` key.
- No automated test suite exists in this repo. Every task's verification
  step is a manual playtest using a local static server
  (`python3 -m http.server 8123` from the repo root, then open
  `http://localhost:8123/index.html`).
- Surgical edits only — don't touch unrelated markup/JS or reformat
  surrounding code.
